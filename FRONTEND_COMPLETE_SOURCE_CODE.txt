KEY FILES (short descriptions)
================================================================================
- src/main.tsx: mounts <App /> and imports global styles.
- src/app/App.tsx: provides the main UI layout, global CSS injection, sample data and many reusable components (TealButton, Field, PasswordField, ProgressBar, StatCard), skeleton loaders, charts and dashboards. This file is a large single-file application used for prototyping the UI.
- src/app/components/ui/*: collection of small, focused UI primitives used across the app. Each component follows a consistent design system and uses Tailwind classes.
- src/styles/*: Tailwind and custom CSS variables, global styles and font imports.

FRONTEND ARCHITECTURE
================================================================================
- Vite development server serves the app (fast HMR).
- App is a single-page React application.
- Component-driven architecture: small reusable primitives in src/app/components/ui, larger page-level components live in App.tsx or dedicated files.
- Data fetching: The frontend is designed to call the backend API at endpoints under /api/* (auth, modules, quiz, nasa-tlx, results, admin). Use fetch or your preferred HTTP client to make requests; authentication uses JWT access tokens in `Authorization: Bearer <token>` header.
- State management: Local React state and component-level state are used; no global store is present in the current snapshot (can be added if needed: Redux, Zustand, or Context API).

DATA FLOW (typical interactions)
================================================================================
1. User registers / logs in via POST /api/auth/login or /api/auth/register.
2. On successful auth, store access token and optionally refresh token.
3. Call GET /api/modules to fetch available modules and render module list.
4. When user opens a module, fetch module content and any associated quiz questions.
5. Submit quiz answers to POST /api/quiz/submit and render results.
6. Admin UI calls /api/admin/* endpoints for analytics and CSV export.

STYLING & DESIGN SYSTEM
================================================================================
- Tailwind CSS utility classes compose the UI styling.
- Theme variables and small CSS injections exist in App.tsx to handle custom animations (shimmer), range input styling, and scrollbars.
- Icons: lucide-react
- Charts: recharts for visual analytics (BarChart, LineChart, ResponsiveContainer)
